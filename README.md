# IT340 — Web Design and Management

Coursework for **IT-340: Web Design and Management** at Juniata College.

This repo contains homework, labs, and weekly projects covering HTML, CSS,
JavaScript, responsive design, CRUD interfaces, and React development with
the MERN stack.
