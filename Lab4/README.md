# Lab 4

## Design Considerations

When designing my website, I tried to pick a small, consistent color pallete and lay things out logically
on the page. Because I wanted my Lab 4 work to be inspiration and a template for Homework 4, I picked a
color pallete which I could use on my homework as well. My plant cards are simple but clean, and I tried
to make color choices that were readable but still fit with the overall vibe of the website. I chose to
use a simple grid layout for my plant cards. On large screens, there will be three columns of content. On
small screens or mobile layouts, I can use CSS to easily compress this into one. With the admin page, I
wanted to build something true to the concept of the site while also clearly supporting CRUD operations.
I deciced what made the most sense was to go with a vertical list of the plants currently in the database
while supporting some basic administrative options a user may want.
