# Homework 4

## Design Considerations

When designing my website, I tried to pick a small, consistent color pallete and lay things out logically
on the page. I chose a simple 5-color pallete from Coolors that focused on woodsy greens and a light blue
accent color. I wanted to design my plant cards in a way that made visual sense, so I used a grid layout
to display the cards and then used flexboxes within cards themsevles to lay out content. Unlike Lab 4 where
images were displayed vertically, I decided to use a flex row approach to display images alongside text content.
I wanted to put the search bar front and center on the homepage along with introductory text, so it felt like
searching for a plant or finding information was the primary goal of the website.
